# RecallMap submission checklist

Nothing in this checklist records deployment, publication, repository sharing, or submission completion yet. External actions remain pending explicit approval.

## Submission assets

- [ ] Production URL is deployed and the built-in demo is verified live.
- [ ] Repository is public, or private access is shared with both official judging addresses.
- [ ] README is reviewed in the exact submitted repository revision.
- [ ] Public YouTube demo is narrated in English and no longer than three minutes.
- [ ] English project description is final and matches the demonstrated product.
- [ ] Education category is selected.
- [ ] Primary build task's `/feedback` Codex Session ID is recorded.
- [ ] Test account requirement is stated as “none,” and built-in sample data is available.

## Production acceptance

- [ ] A judge can start the built-in lesson without an account or personal API key.
- [ ] The deployed Guided Focus flow completes from start through verification.
- [ ] Diagnosis returns three to five typed nodes with source-verified evidence.
- [ ] The challenge targets one gap, or uses a transfer question when all nodes are correct, without disclosing a complete answer or fabricating an error.
- [ ] Verification visibly compares the original and revised explanations.
- [ ] API failure and browser refresh preserve student work in production.
- [ ] Unit, route, component, E2E, lint, production audit, and build gates pass for the submitted revision.
- [ ] README and video distinguish Codex's development role from GPT-5.6's runtime role.
- [ ] A narrated rehearsal finishes at or below 3:00.

## Deadline and buffer

- Official deadline: **July 21, 2026 at 5:00 PM PDT**, which is **July 22, 2026 at 09:00 JST**.
- Internal target: **July 21, 2026 at 09:00 JST**, preserving a 24-hour buffer for deployment, repository access, video processing, `/feedback`, and final form checks.
- [ ] Final submission is completed before the internal target.
- [ ] Production URL, repository access, video visibility, `/feedback` Session ID, English copy, sample data, and Education category are rechecked inside the final buffer.
